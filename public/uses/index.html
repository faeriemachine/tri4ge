Operating System

I use EndeavourOS as my choice of operating system for my desktop PC, which is an Arch-based Linux distribution. It's a lightweight distro that ships with a minimum amount of preinstalled apps, making it almost like a blank canvas that's ripe for personalization. Highly recommend it if you're looking for the Arch Linux experience, but want something a bit easier to install and manage than Arch itself.

I also use EndeavourOS on my laptop, but I used to use Linux Mint on it for a good while, on the Cinnamon desktop environment. However, as I've started to use my laptop more due to needing to rest in bed more often, I decided to make the switch to a distro that supports KDE Plasma 6, since it's easily my favourite DE at the moment. I enjoyed my time using Mint, and I do still recommend it as a good entry-level Linux distro, but it didn't have everything I've come to love about Arch-based systems.

Art

For digital art, I use Procreate on an iPad 9th generation with a 1st generation Apple Pencil the most. I also use Krita on an XP-Pen Artist Pro 13.3", but only on rare occasions since this tablet causes me a great amount of pain.

For 3D modeling, I use Nomad Sculpt on my iPad for the actual sculpting, CozyBlanket for retopology, and B For Artists for any final adjustments.

Traditionally, I use Ohuhu alcohol markers, Prismacolor Scholar pencil crayons, Mungyo Gallery soft oil pastels, and Gellyroll gel pens on Ohuhu 7.6" x 10" 200GSM marker pad paper.

Digital brushes

Currently, I use an untextured version of the default Studio Pen available in Procreate on various opacity percentages for nearly everything, but I sometimes like to use these Copic-inspired brushes as well. I've also created a brush based on this Instagram tutorial for shading with rim lighting.

Fursuit Building

My choice of sewing machine is a Singer 328J from the 1960's using Singer size 16 needles. I usually use Gütermann polyester thread when machine sewing, as well as their upholstery thread for hand sewing.

I don't get my fabric from just one source, and many of my sources can be found on the links page. For head lining I do stick with using Big Z's color-fast (non-bleeding) techno neoprene the most, however. I also prefer to cuff handpaws with ribbed knit cuffing fabric.

Information about 3D printing will be available when I start 3D printing suit parts in the future.

Other tools of the trade include:

  • Fiskars spring-loaded scissors (cutting fabric)
  • Gorilla Glue high-low temp glue gun & glue sticks
  • Fuzzbutt Fursuits' Mannie the mannequin head
  • Tailor's chalk (marking stretchy fabric, I.E. neoprene)
  • Sewing clips (alternative to pins)
  • Sminiker pet clippers
